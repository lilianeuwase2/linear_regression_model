# Maize Yield Predictor App

A one-page Flutter app that predicts maize yield (tonnes per hectare) using my API.

## How to run

1. Install Flutter and start an Android emulator.
2. In this folder, run:
   ```bash
   flutter pub get
   flutter run
   ```
3. Fill in the 10 fields, for example: `Rwanda`, `900`, `20`, `1.2`, `40`, `20`, `yes`, `yes`, `no`, `no`.
4. Tap **Predict** to see the yield.
